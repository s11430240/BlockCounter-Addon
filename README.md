# BlockCounter Minecraft Bedrock Addon

## 專案簡介

BlockCounter 是一個基於 Minecraft Bedrock Script API v1.17.0+ 開發的方塊統計與全息投影預覽模組。

玩家可以使用專用工具選取區域、統計其中的方塊數量，並在目標位置即時預覽準備貼上的結構。

## 版本與發布

- 目前版本：1.1.5
- 最低需求：Minecraft Bedrock 1.21.70（使用所有可用方塊的篩選清單）。
- 玩家進入世界或重生後約 2 秒，聊天欄會顯示目前載入的 BlockCounter 版本；開啟方塊統計控制台時，也可在標題查看版本。
- 投影材質缺少對照或屬性設定失敗時，聊天欄會顯示診斷訊息，方便回報無法辨識的方塊。
- 複製結構後即可在主選單旋轉投影；尚未設定投影位置時，旋轉角度會保留並套用到之後建立的預覽。
- 過濾設定可搜尋並從遊戲方塊清單直接選取要排除統計的方塊。
- 每次功能或修正更新時，同步更新本文件、行為包／資源包版本與 `BlockCounter.mcaddon`。
- 完成檢查後，將相關檔案提交並推送至 GitHub `main` 分支。

## 核心功能

- 手持工具選擇 P1/P2 座標，並統計選取區域內的方塊數量
- 全息投影即時預覽，支援 0°、90°、180°、270° 連續旋轉調整
- 貼上起點以 P1 對齊，選區另一角 P2 不會影響結構錨點
- 非完整方塊備援渲染機制，支援階梯、半磚、按鈕等方塊以對應的完整方塊材質顯示
- TNT、附魔台、書櫃、門與蒼白苔蘚地毯支援依方塊面套用材質；火把、按鈕、地板門、床與地毯依種類或顏色狀態選擇材質
- 舊式木材方塊依木種狀態顯示對應材質；未知方塊以提示貼圖標示
- 支援全息投影互動與生存模式材料放置功能
- 提供結構貼上與上一次操作復原功能

## 預計開發項目

- 手動輸入座標（X、Y、Z）的全息投影 UI 介面

## 目錄結構

```text
BlockCounter_Build/
├── BlockCounter_BP/
│   ├── manifest.json
│   ├── blocks/                 # 方塊定義與方塊相關資料
│   ├── entities/               # 行為包中的實體定義
│   ├── items/                  # 工具與物品定義
│   └── scripts/
│       └── main.js             # Script API 主程式：統計、投影、旋轉與互動邏輯
└── BlockCounter_RP/
    ├── manifest.json
    ├── entity/                  # 客戶端實體定義
    ├── models/entity/           # 全息方塊的幾何模型
    ├── render_controllers/      # 材質索引與渲染控制
    └── textures/                # 方塊、實體與物品貼圖
```

### BlockCounter_BP

行為包（Behavior Pack），負責遊戲邏輯，包括 Script API 腳本、工具與物品行為、方塊定義，以及全息投影的建立與管理。

### BlockCounter_RP

資源包（Resource Pack），負責客戶端顯示，包括全息實體模型、渲染控制器、材質索引與各類貼圖。
